# FUTURUM Search

Неофициальный поиск по каталогу Parapa mall: быстрый поиск, избранное, каталог с историей цен.

## Запуск сайта локально

```bash
py -3 serve.py
```

Открой [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

## Постоянный мониторинг (рекомендуется)

Плавно, по кругу: ищет **новые** предметы и обновляет **цены** пачками — не долбит весь сайт разом.

```bash
py -3 watch_catalog.py
```

Или двойной клик: `watch_catalog.bat`  
Остановка: `Ctrl+C` (курсор сохранится, продолжит с места).

Каждый круг:
1. проверка хвоста id на новинки  
2. обновление следующей пачки известных (цены/скидки)  
3. история цен  
4. push на GitHub, если что-то изменилось  

За несколько кругов проходит весь каталог и начинает сначала.

| Флаг | Значение |
|------|----------|
| `--batch 25` | сколько известных обновлять за круг |
| `--sleep 120` | пауза между кругами (сек) |
| `--once` | один круг и выход |
| `--no-push` | без заливки на GitHub |

## Разовый сбор / заливка

```bash
py -3 update_and_push.py
```

| Флаг | Что делает |
|------|------------|
| *(без флагов)* | новые id + картинки + история + push |
| `--scrape` | полный обход всех id (долго, редко нужен) |
| `--enrich` | дозаполнить описания |
| `--dry-run` | только отчёт |

Сайт после push:  
https://dramitelego-netizen.github.io/futurum-search/

## Возможности

- Поиск с опечатками и синонимами
- Тёмная / светлая тема и пресеты фона
- Избранное (в браузере + на сервере)
- Страница каталога со сортировкой и историей цен
- Локальные иконки и look-картинки (`data/img/`)

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` / `app.js` | Поиск |
| `catalog.html` / `catalog.js` | Каталог |
| `serve.py` | Сервер, `/proxy`, `/api/favs` |
| `data/items.json` | Каталог предметов |
| `data/price_history.json` | История цен |
