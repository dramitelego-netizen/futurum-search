# FUTURUM Search

Неофициальный поиск по каталогу Parapa mall: быстрый поиск, избранное, каталог с историей цен.

## Запуск сайта локально

```bash
py -3 serve.py
```

Открой [http://127.0.0.1:8080/](http://127.0.0.1:8080/)

## Сбор данных и заливка на GitHub

Один скрипт с подробным логом — что делает, что собрал, какие файлы заливает:

```bash
py -3 update_and_push.py
```

Или двойной клик: `update_and_push.bat`

| Флаг | Что делает |
|------|------------|
| *(без флагов)* | картинки + история цен + commit/push |
| `--enrich` | ещё дозаполнить пустые описания |
| `--scrape` | полный обход товаров по id (долго) |
| `--dry-run` | только отчёт, без commit/push |
| `--no-push` | собрать данные, но не заливать |

После push сайт обновляется:  
https://dramitelego-netizen.github.io/futurum-search/

## Возможности

- Поиск с опечатками и синонимами
- Тёмная / светлая тема и пресеты фона
- Избранное (в браузере + на сервере)
- Страница каталога со сортировкой и историей цен
- Локальные иконки и look-картинки (`data/img/`)

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` / `app.js` | Поиск |
| `catalog.html` / `catalog.js` | Каталог |
| `serve.py` | Сервер, `/proxy`, `/api/favs` |
| `data/items.json` | Каталог предметов |
| `data/price_history.json` | История цен |
