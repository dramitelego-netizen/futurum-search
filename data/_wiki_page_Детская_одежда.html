Игровое колесо удачи

Зимнее колесо удачи

Способ получения: зимнее колесо удачи, билет "Зимняя удача"

  • Синий комплект "Бельвиль" (ж) / (м)
  • Черный комплект "Бельвиль" (ж) / (м)
  • Красный комплект "Бельвиль" (ж) / (м)
  • Белый комплект "Бельвиль" (ж) / (м)
  • Костюм "Теленок" (ж) / (м)

Солнечное колесо удачи

Способ получения: солнечное колесо удачи, билет "Солнышко"

  • Черный костюм "Арисаро" (ж) / (м)
  • Белый костюм "Арисаро" (ж) / (м)
  • Красный костюм "Арисаро" (ж) / (м)
  • Желтый костюм "Арисаро" (ж) / (м)

Большое колесо удачи

Способ получения: большое колесо удачи, билет "Большая удача!"

  • Черный наряд "Кероль" (ж) / шорты
  • Белый наряд "Кероль" (ж) / шорты
  • Костюм "Роэкс" (м)
  • Комплект "Фанатка панды" (ж) / "Фанат панды" (м)
  • Черный комплект "Лунная фея" (ж) / "Лунный принц" (м)
  • Белый комплект "Лунная фея" (ж) / "Лунный принц" (м)

Колесо удачи "Бархатный сезон"

Способ получения: колесо удачи "Бархатный сезон", билет "Бархатный сезон"

  • Черный костюм "Багатель" (ж)
  • Белое платье "Багатель" (ж)
  • Розовое платье "Багатель" (ж)
  • Красное платье "Багатель" (ж)
  • Белое платье "Лива" (ж)
  • Красное платье "Лива" (ж)
  • Розовое платье "Лива" (ж)
  • Черное платье "Лива" (ж)
  • Белый костюм "Лассе" (м)
  • Красный костюм "Лассе" (м)
  • Черный костюм "Лассе" (м)
  • Розовый костюм "Лассе" (м)
  • Красный костюм "Галвей" (м)
  • Черный костюм "Галвей" (м)
  • Белый костюм "Галвей" (м)
  • Розовый костюм "Галвей" (м)
